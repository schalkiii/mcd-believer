# 麦门画像手册（口味记忆 / 人设统计 / 分享卡 / 省心模式）

目标：让助手**记住你**——积累口味偏好、消费人设、可分享的年度报告，并按用户状态调整输出方式。这是"全场景管家"区别于单品工具的灵魂场景。

## 1. 口味记忆（本地 profile，跨对话生效）

约定在工作目录维护 `mcd-profile.json`（首次自动创建），字段：

```json
{
  "defaultStore": { "storeCode": "", "storeName": "", "beType": 1 },
  "deliveryAddressId": "",
  "likes": ["巨无霸"], "disables": ["酸黄瓜", "香菜"], "spicy": "no",
  "budget": 30, "kcalTarget": 550, "drink": "零糖可乐",
  "lastOrderSummary": ""
}
```

规则：
- **会话开始**：若文件存在，读取并优先套用（默认店、忌口、预算、热量目标），一句话确认"按老样子？"。
- **每次下单/选品后**：把新偏好写回（如用户连续两次去掉酸黄瓜 → 加入 `disables`）。
- **老样子复购**：`order-list` 取最近一单 → 提取 `productCode` 列表 → `calculate-price` 实时重核价与在售状态（缺货/涨价要说明）→ 确认后 `create-order`。这是"一句话复购"链路，多数场景 Skill 未做。
- 用户明确说"别记住我"时停止读写。

## 2. 麦门年报 / 人设分享卡

数据源：`order-list`（近单）、`query-my-account`（积分）、`query-my-coupons`（券包）。聚合维度（只统计真实返回，禁止编造）：

- 消费总额 / 单数 / 最贵一单 / 最晚下单时间（从订单时间字段）
- 高频餐品 Top5（"你的本命是___"）
- 品类占比：汉堡/小食/甜品/饮料（按 tags 或分类归并）
- 积分使用率：已花积分 ÷ 累计获得（"会过日子型 / 囤积型"）

人设标签玩法（可选其一，语气娱乐化、数据真实）：
`早餐打卡员 / 深夜麦门徒 / 薯条纯爱党 / 甜筒收藏家 / 零糖特调师 / 精算省钱家 / 积分守财奴 / 团餐大家长`。

**确定性实现**：`scripts/card.py` 已落地两张分享卡——`render_fortune_card`（麦门灵签卡）与 `render_persona_card`（年报人设卡）：单文件竖屏 HTML、品牌红金配色、零外部链接、为手机截图设计；人设标签由 `derive_persona` 按确定性规则推导（深夜占比≥30% → 深夜麦门徒；本命含薯条 → 薯条纯爱党……同输入必得同结果）。运行 `python scripts/card.py` 生成到 `demo_output/`。

输出为一张 Markdown 分享卡（标题 + 数据行 + 人设一句点评），用户可复制发朋友圈。

## 3. 省心模式（无障碍 / 极简输出）

当用户表明视障、开车、长辈使用、或说"简单点讲"时，切换输出纪律：
- 每轮**只说一句话/一个选择**，不列表格、不用层级符号；
- 价格、取餐码用中文口语读法（"三十二元五角"可写作"32块5"）；
- 重要信息（支付链接、取餐码）**单独一条消息重读一遍**；
- 下单链路不变，仍遵守全局铁律的确认流程。

## 4. 场景触发语

- "按老样子来一份" → §1 复购链路
- "我一年在麦当劳花了多少？给我出张报告" → §2
- "我妈要用，你讲简单点" → §3
- "你还记得我不吃酸黄瓜吗" → §1（读 profile 并确认）
